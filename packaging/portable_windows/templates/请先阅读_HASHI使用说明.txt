HASHI Windows 便携版使用说明
============================

一、第一次使用
--------------

1. 请双击 USB 根目录中的：

   安装_HASHI_到本机.bat

2. Windows 询问是否允许更改设备时，请选择“是”。HASHI 需要管理员权限，
   才能在本机启动完整功能和访问您授权的磁盘。

3. 安装程序会把完整的 HASHI 工作副本复制到本机，并逐个验证文件。窗口会显示
   真实的复制和验证进度。安装完成前请勿关闭窗口，也不要拔出 USB。

4. 看到“按任意键启动 HASHI”后，按任意键即可直接进入聊天界面，不会再出现
   第二个选择菜单。


二、安装后如何启动和停止
------------------------

安装成功后，桌面会出现三个中文快捷方式：

  启动 HASHI（聊天界面）
    启动 HASHI，并打开文字聊天终端。

  启动 HASHI（工作台）
    启动 HASHI，并在 Edge 或 Chrome 中打开完整工作台。

  停止 HASHI
    安全停止这个 HASHI 实例及其专用工作台浏览器。

这些快捷方式指向本机安装目录，因此安装完成后不需要插着 USB。使用结束时，
请先运行“停止 HASHI”，再关闭窗口。


三、USB 根目录中的文件
----------------------

  安装_HASHI_到本机.bat
    第一次在这台电脑上使用时运行。若 HASHI 已正确安装，它不会重复复制文件，
    只会修复桌面快捷方式并打开现有安装。

  启动_HASHI_聊天界面.bat
    从 USB 打开本机已经安装好的聊天界面，不会直接从 USB 运行 HASHI。

  启动_HASHI_工作台.bat
    从 USB 打开本机已经安装好的工作台。

  停止_HASHI.bat
    停止本机 HASHI。

  诊断_HASHI.bat
    检查安装、运行环境、端口和必要组件，不会发送模型请求。

  从本机卸载_HASHI.bat
    从当前电脑彻底删除本机副本。详细风险请先阅读下面的“卸载”。


四、HASHI 安装在哪里
--------------------

本机安装目录：

  C:\HASHI-Portable\

日常使用产生的内容都保存在本机副本中，包括对话、设置、日志、SQLite 状态、
浏览器配置和 API 密钥。HASHI 不会直接从 USB 运行，因此速度不受 USB 读写影响。

主日志：

  C:\HASHI-Portable\data\logs\bridge.log

当前实际端口和进程身份：

  C:\HASHI-Portable\data\state\local-endpoint.json

Agent 行为说明文件：

  C:\HASHI-Portable\data\workspaces\portable\agent.md

如果您修改了 Agent 行为说明，请使用 UTF-8 编码保存，然后停止并重新启动 HASHI。
USB 内作为安装来源的对应文件位于：

  <USB 盘符>:\data\workspaces\portable\agent.md


五、本机连接方式
----------------

HASHI 只使用安全的本机回环地址 127.0.0.1。它会优先使用配置端口；如果端口已经
被占用，会自动向 Windows 申请一个可用端口。聊天界面和工作台只读取由当前 HASHI
进程写入并经过身份验证的端点，不会经过 WSL，也不会尝试 172.x 地址。


六、再次运行安装程序
--------------------

如果这台电脑上已经存在身份匹配且完整有效的 HASHI，本安装程序不会覆盖它，也不会
重新复制 USB 内容；它只会修复中文桌面快捷方式，然后打开现有安装。

如果目标目录存在，但身份、所有权标记或文件结构不正确，安装程序会安全停止，不会
覆盖未知目录。


七、卸载（请谨慎）
------------------

请从最初安装所使用、身份匹配的 USB 运行：

  从本机卸载_HASHI.bat

按照提示输入 REMOVE 后，卸载程序会先停止 HASHI，删除已知桌面快捷方式，然后只
删除经过身份验证的本机目录：

  C:\HASHI-Portable\

此操作会永久删除本机中的对话、设置、日志和明文 API 密钥，无法恢复。USB 内容不会
被删除。如果身份、目标路径、所有权标记或目录安全检查不通过，卸载程序不会删除内容。


八、安装或启动失败时
--------------------

请先双击：

  诊断_HASHI.bat

安装日志临时保存在：

  %TEMP%\HASHI-Portable-install.log

“安装完成”和“随后启动成功”是两个独立状态。如果复制和验证已经完成，但启动失败，
程序只会报告“HASHI 启动失败”，不会错误地说安装失败。


九、系统与功能说明
------------------

- 支持 Windows 10/11 x64。
- 自带所需 Python、Node、FFmpeg、OCR 和语音组件。
- 无需安装 Git、npm、pip 或 WSL，不创建 Windows 服务，不写入卸载注册表，也不修改
  系统 PATH。
- 只使用原生 Windows 运行环境；缺少 Windows 执行器时会明确报错，不会绕到 WSL。
- 顶层只提供 HER v2；默认使用 DeepSeek 官方 API，也可配置 Qwen/DashScope。
- 聊天界面和工作台默认共享同一条对话。
- 支持浏览器、桌面工具、Remote、HChat、Scheduler、Nagare 和 Superloops。
- 不包含本地大语言模型，不能离线生成回答。
- LAN 一键配对凭证有效期为七天；局域网本身不等于获得信任。

本 USB 建议使用 NTFS 与默认 4 KiB 分配单元。拔出前请先停止 HASHI，并使用 Windows
“安全删除硬件”。
