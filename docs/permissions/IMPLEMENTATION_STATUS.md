## 当前实现

| 部分 | 已实现的行为 |
| --- | --- |
| L0 | 缺省及显式 L0 在外层保留原执行路径；不创建权限账本、服务连接、租约或新工具。既有隐私与其他防护继续生效。 |
| 权限权威 | PAO 绑定 Task/Run/Turn/epoch；权限服务持有决定、范围、期限、单次用权、撤回与撤权事务。旧执行先失效，未知副作用不得换 ID 重放。 |
| 人类批准 | 公共认证会话和明确的人类用户到 PAO owner 关联；共享 /safety 命令与 opaque action。原生命令另需明确外部身份关联，合成 API actor 不登录。普通问答从不授权。 |
| 完整运行路径 | 现行 HERV3 singleloop、私有 Provider checkpoint、原 Run 暂停、批准后新 epoch、沿用原待执行操作。服务失联不自动变成 L0 或其他后端。 |
| 文件与 HTTP | 实际 Windows 对象绑定、固定 helper、原子 start 栅栏；目录、搜索、补丁；固定 DNS/目标、无自动重定向/环境代理；具名凭证单独授权和遮盖响应。GET 的 URL 同样声明 send。 |
| 结构化脚本 | 固定输入快照、离线 Python、临时输出；用户代码仅在 LPAC 进程执行。脚本、helper 和 Safety Job 有独立 owner，原生进程数/内存限制，独立加密结果和 profile 收尾。 |
| 媒体与原有服务 | 仅传输当前接收的附件并核对内容；语音确认、TTS、音频成果继续使用原 owner。Persona、草稿、习惯、Meditation、TurnServices 和原压缩包装接回原处理方。 |
| 用量 | HTTP 前保存 intent，响应后记录实际用量；host 与 Worker 调用均有稳定物理身份、先持久化投影再通知原计费 owner。恢复读取原记录，不重发模型请求来推测旧结果。 |
| 兼容与状态 | 用户明确选其他后端时继续 unmanaged，先以 PAO 停止旧执行；清理失联保留未确认状态。实际控制按当前绑定、工具库存、观测和依赖投影，配置不能直接产生 enforced。 |
| 安装 | 显式可替换 Functions/sidecar 入口、密钥分工、封闭只读 capsule、真实 Windows SID/PID 与 Job 检查。L1 不要求独立 Runner 或非管理员组成员资格，但拒绝提升执行；L2 保持独立普通账户检查。 |

## 本轮必要验证

- 文件启动前失败已做 red/green：未执行即失败会正常返回并可恢复同一结果；没有 claim，也不消耗单次授权。已准备/已开始的操作不能走这个路径。
- 真实 Windows 私有 pipe、完整服务与 SDK、现行 HERV3、可信人类批准、新 epoch 和真实临时文件写入的组合闭环通过；仅两次模型 transport、一次文件写入。模型 transport 与原生文件 launcher 在该用例中注入，不将它冒称完整 L2。
- 附件内容变化、任意路径取件拒绝、原 Safe Voice 确认、原压缩/草稿包装、原文本转音频范围通过针对性检查。音频成果进入真实资产 store，绑定原 owner/session，不留在临时 host。
- 共享原生命令经实际私有服务路由批准；未关联用户、合成 API actor、PAO 面伪造登录和旧 Session 均拒绝。真实客户端的 view protocol 问题已修复。
- Worker 用量投影在 observer 失败前保存；后继 epoch 保留原阶段和稳定 ID。脚本结果在 profile 清理失败时保留，不重跑；旧物理行失败不跳过其他行；已完成清理的旧快照无需已删除 plan。
- 前述重点组合分别有 31、80、53、41、87 项通过记录；存在重叠，不能相加作为总量。收尾新边界组和私有通信组合已通过。最终当前提交的 CI 同组回归及 curated core gate 仍待收齐。
- Windows 实体脚本试验：新建专用一次性测试身份/配置及私有临时目录，执行固定 probe；首次在受限进程运行超时。账户、配置及 staging 均为 cleaned。此项保持失败，不能计通过；新增阶段观察后正在定位。
- 此前实体 LPAC、held-handle helper、私有 IPC 的证据保留，但不代替当前版本脚本/完整安装资格。

## 实际边界与发布门

任意 shell、依赖安装、未评定设备/浏览器/桌面、自定义远程工具和第三方后端不能从管理服务静默逃逸；当前安装 profile 未提供的能力显示 unavailable，选择兼容后端则如实 unmanaged。脚本原文件仅作输入，正式输出保存仍经文件代理；临时目录监测是软限制，不是磁盘硬配额。

混合部署中，审批端/桌面与未受管 Agent 的隔离尚无实体观测时，审批及依赖控制保持 partial，不显示完整 L2。配置一个 L2 数字或通过独立组件测试都不能改变这一点。
