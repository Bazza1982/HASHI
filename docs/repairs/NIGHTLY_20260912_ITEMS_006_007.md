## Scope and changes

### HN-20260911-006 — Telegram recovery ownership

- `426a2523` assigns every Agent incarnation a stable lifecycle UUID and binds
  Telegram recovery state to instance, lifecycle and a domain-separated bot
  fingerprint. Raw bot tokens are never persisted.
- Delivery state has one revision-checked, cross-process-safe atomic owner.
  Unowned legacy records and identity mismatches are quarantined without an
  outbound recovery notice.
- A recovery claim is persisted before sending. A result can settle only the
  exact owner, incident, chat and claim that initiated it, so cleanup, Move,
  Clone or a newer incident cannot be overwritten by a late result.
- Telegram errors retain typed meaning across the Function Worker RPC.
  Permanent destination errors stop only that chat; `RetryAfter` preserves its
  exact window; transient failures use bounded retry. Unknown send outcomes
  remain unsent rather than being reported as delivered or replayed blindly.
- Move transfers only state proven to belong to the moved lifecycle. Clone and
  delete/recreate receive a new lifecycle and do not inherit old recovery
  notices. Rollback and repeat-commit paths keep the same transaction identity.

### HN-20260911-007 — executable tool catalogue

- `04fab030` makes the shared Tool Registry intersect configured permission
  with a live, same-instance Capability Broker lease and the action actually
  supported by that Worker.
- Registration, heartbeat, expiry and recovery broadcast one topology fact to
  Function Workers. Isolated gateways query the same Workbench endpoint.
- A second pre-dispatch check closes the catalogue/execution race and returns
  typed `capability_unavailable` with a reason and next step instead of an
  unexpected exception or blind retry.
- `web_fetch` remains visible for ordinary public documents and explains that
  JavaScript, login state and interaction require a live Browser Worker.
- `100446a7` separates a WSL instance's `BridgeHome` from a Windows-local
  Scheduled Task `CodeRoot`, removes PowerShell provider-qualified paths from
  persisted arguments, and isolates device-worker logs by instance.
