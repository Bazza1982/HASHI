

## 2026-11-03 — Bounded speech tasks and outcome recovery
PAO speech owns asynchronous Workbench preparation/generation, exposed through existing Functions IPC and authenticated Workbench operations. Core and the native process owner are unchanged. A start identity is durably recorded before execution; duplicate starts recover the same task, conflicting content is rejected, and unfinished tasks after owner restart are uncertain, never replayed. A 600-second result cache is bounded to 64 results/64 MiB; only hashes and bounded metadata remain as tombstones (10,000-task admission cap). This transient cache is not an ordinary prompt/audio archive; durable requested recordings remain the Frontend Connector's responsibility.

Budgets estimate pronunciation units, audio duration, conservative initial RTF, cold/queue reserve and margin. Recent per-selection P95 observations may raise the estimate. Native generation is capped at 120 seconds per segment; over-budget segments are rejected before execution for client splitting. Preparation and generation are distinct phases. The single task owner permits at most two attempts within one total budget, retrying only an explicit unaccepted 429; nested provider retries/fallback are disabled for these tasks. Unknown network/native outcomes are not retried. The remaining phase budget is forwarded to Compute. Short status HTTP deadlines are transport safeguards and no longer define generation duration. Cancellation prohibits late publication; native ownership/completion fences remain Compute-owned.
Validation includes lost delivery, duplicate/conflicting IDs, restart, cancellation with a late executor, deadline suppression, provider retry ownership, typed IPC results and long-text splitting. Actual model calibration and deployment evidence are reported separately.

Calibration separates fixed cold/prefill reserves from per-unit cost. Very short generation/planning samples cannot inflate later long-input slopes; planning retains its existing 90-second cap and explicit plain-reading failure behavior. Regression: a cold one-character reading must not make a later normal segment impossible.
